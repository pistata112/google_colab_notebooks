# google_colab_notebooks

Collection of Google Colab notebooks for experiments, demos, and reproducible analyses.

## Overview

This repository contains Jupyter notebooks (.ipynb) formatted to run in Google Colab. Use these notebooks to run code without local setup.

## How to use

- Open any notebook in Colab by clicking the notebook file and selecting "Open in Colab", or use the URL pattern:

  https://colab.research.google.com/github/pistata112/google_colab_notebooks/blob/main/<path-to-notebook>.ipynb

- Run cells sequentially. Install any required packages using `!pip install` at the top of the notebook.

## Notebooks

See the repository file list for available notebooks (.ipynb). Each notebook should include usage notes and required dependencies at the top.
